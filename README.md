# ГоркиLand · Комплексная металлообработка

Статический русскоязычный сайт. Сервис заявок не нужен: посетитель получает прямой телефон и ссылку на письмо с шаблоном запроса. Чертёж или 3D-модель он прикладывает в своей почтовой программе.

## Локальный запуск

Требуется Node.js 20 или новее. npm-пакетов для сборки нет.

```sh
npm run build
npm run preview
```

Если Node.js установлен без npm, те же команды — `node build.mjs` и `node preview.mjs`.
Откройте [превью](http://127.0.0.1:4173/gorkilandproduction/). Другой порт можно указать командой `node preview.mjs 4180`.

| Раздел | URL |
|---|---|
| Главная | `/` |
| Услуги и возможности | `/services/` |
| Оборудование | `/equipment/` |
| Типовые изделия | `/products/` |
| Производство и конструкторское бюро | `/production/` |
| Контакты и расчёт | `/contacts/` |

Маршруты в таблице отсчитываются от `/gorkilandproduction/`. У каждой страницы свой `index.html`. Ссылки и ресурсы относительные. Канонические URL и карта сайта используют адрес проекта GitHub Pages.

## Источники сайта

Редактируемые тексты и данные находятся в `src/content.mjs`, шаблоны страниц — в `build.mjs`, стили — в `src/site.css`. Оптимизированные изображения и Inter лежат в `src/assets/`. Исходные материалы и вопросы согласования хранятся вне этого каталога проекта.

## Публикация после согласования

1. Подтвердить репозиторий `https://github.com/kislitsyna01/gorkilandproduction.git`, основную ветку `main` и допуск отобранных фотографий. Сверить содержание с итогом согласования.
2. В настройках репозитория открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Добавить файлы этого каталога в ветку `main`. Существующее содержимое репозитория сначала сверить. Ветка запускает `.github/workflows/pages.yml`, который собирает `dist/` и публикует его. Для повторного запуска доступен **Actions → GitHub Pages → Run workflow**.
4. Открыть адрес из задачи **Publish**. Ожидаемый адрес проекта — `https://kislitsyna01.github.io/gorkilandproduction/`. Проверить страницу услуг и прямые URL остальных разделов, изображения, шрифт, телефон, почту и основное действие для расчёта.

Если адрес публикации поменяется, обновите `origin` в `build.mjs`. Если поменяется путь проекта для локальной имитации GitHub Pages, также обновите `base` в `preview.mjs`.
